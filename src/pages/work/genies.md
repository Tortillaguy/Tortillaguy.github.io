Genies makes 3D avatars. I joined in March 2020 as a senior Unity developer, working on the avatar app and the pipeline that gets new 3D content into it.

## The pipeline

Getting an artist's new clothing or accessory into the app used to take weeks. I built Python microservices for the 3D asset pipeline that cut it to under 30 minutes, and used Unity Asset Bundles so new content could ship to the app as downloadable content instead of waiting for an app release.

## The new app

For a new mobile app, I designed the core architecture: data flow, API fetching, caching and client-side state, written up as the UML diagrams the team built from. I led technical planning for its main features, a 3D avatar customization system, an in-app cosmetics shop, and sharing across platforms by SMS.
